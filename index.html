Excelマクロ・VBAでできること

Excelの作業を自動化する「マクロ」と、それを支える「VBA」について、 図や具体的なコード例を使いながら、初心者向けにわかりやすく紹介します。

VBAってなに？ コピー Range / Cells ループ 条件分岐 色・文字色 フォルダ読み込み 注意点とまとめ

1. VBAってなに？ / AI時代に学ぶ意味

マクロは「作業を自動化する仕組み」、VBAは「その仕組みを作るための言語」です。 今どきはAIにコードを書いてもらうこともできますが、仕組みを理解していると、 AIへの依頼がしやすくなり、出てきたコードの意味もなんとなく分かるようになります。

VBAの役割と、AI時代に学ぶ意味を図で整理したイメージ

ここが大事
すべてのコードを暗記する必要はありません。 「何ができるのか」「どういう仕組みで動くのか」を知っておくことで、 AIにより具体的に依頼できるようになります。

2. セルのコピー方法

同じ「コピー」でも、全部コピーするのか、値だけなのか、書式だけなのかで使い分けができます。

全部コピー・値だけ・書式だけ・数式ごとの違い

全部コピー

値・書式・数式などをまとめてコピーします。

Range("A1").Copy Destination:=Range("B1")

Application.CutCopyMode = False

値だけコピー

セルの見た目ではなく、値だけをコピーします。

Range("B1").Value = Range("A1").Value

書式だけコピー

背景色や文字色など、見た目だけをコピーします。

Range("A1").Copy
Range("B1").PasteSpecial Paste:=xlPasteFormats

Application.CutCopyMode = False

数式ごとコピー

セルの数式をコピーします。

Range("A1").Copy
Range("B1").PasteSpecial Paste:=xlPasteFormulas

Application.CutCopyMode = False
ポイント
コピー後に Application.CutCopyMode = False を入れておくと、 Excelのコピー状態を解除でき、点線の枠も消えます。

3. セルの指定方法：Range と Cells

VBAでは、どのセルを対象にするかを指定する必要があります。 その基本が Range と Cells です。

RangeはA1形式、Cellsは行番号・列番号で指定

1つのセルを指定

Range("A1")

範囲を指定

Range("A1:C3")

行・列で指定

Cells(3, 3)

Cellsを組み合わせる

Range(Cells(1, 1), Cells(3, 3))
ポイント
Range は見た目で分かりやすく、 Cells はループなどで行番号・列番号を変えながら処理するときに便利です。

4. ループ・繰り返し処理

同じ処理をたくさんのセルに対して行いたいときは、ループを使うと便利です。

For ～ Next、For Each、Do While の基本

For ～ Next

回数を決めて繰り返します。

Dim i As Long

For i = 1 To 10
    Cells(i, 1).Value = i
Next i

For Each

範囲内のセルを1つずつ処理します。

Dim c As Range

For Each c In Range("A1:A10")
    c.Interior.Color = RGB(198, 239, 206)
Next c

Do While

条件が成り立つ間、繰り返します。

Dim row As Long

row = 1

Do While Cells(row, 1).Value <> ""
    Cells(row, 2).Value = "確認済み"
    row = row + 1
Loop

ミニ例：A列をB列へコピー

Dim i As Long

For i = 1 To 10
    Cells(i, 2).Value = Cells(i, 1).Value
Next i

5. 条件分岐

条件分岐を使うと、「もし〇〇ならこの処理、そうでなければ別の処理」という判断ができます。

If、Else、ElseIf を使った判定の基本

If

条件を満たすときだけ処理します。

If Range("A1").Value >= 80 Then
    Range("B1").Value = "合格"
End If

If ～ Else

条件に応じて2通りに分けます。

If Range("A1").Value >= 80 Then
    Range("B1").Value = "合格"
Else
    Range("B1").Value = "不合格"
End If

ElseIf

複数の条件を順番に判定します。

If Range("A1").Value >= 80 Then
    Range("B1").Value = "A"
ElseIf Range("A1").Value >= 60 Then
    Range("B1").Value = "B"
Else
    Range("B1").Value = "C"
End If

ループと組み合わせる

Dim i As Long

For i = 2 To 101
    If Cells(i, 1).Value >= 80 Then
        Cells(i, 2).Value = "合格"
    Else
        Cells(i, 2).Value = "不合格"
    End If
Next i

6. セルの色や文字色を変える

VBAでは、セルの値だけでなく、背景色や文字色、太字や文字サイズなども変更できます。

背景色・文字色・太字・条件付き色分けの例

背景色を変える

Range("A1").Interior.Color = RGB(255, 255, 0)

文字色を変える

Range("A1").Font.Color = RGB(255, 0, 0)

太字・サイズ変更

With Range("A1")
    .Font.Bold = True
    .Font.Size = 14
End With

条件で色分け

If Range("A1").Value >= 80 Then
    Range("A1").Interior.Color = RGB(198, 239, 206)
Else
    Range("A1").Interior.Color = RGB(255, 199, 206)
End If

7. Excel以外もできる：フォルダ読み込み

VBAはExcelの中だけではなく、フォルダ内のファイルを読み込んで一覧化することもできます。

Dir関数を使ってファイル名を順番に取得するイメージ

ファイル名を取得して表示

Dim fileName As String

fileName = Dir("C:\Sample\*.*")

Do While fileName <> ""
    Debug.Print fileName
    fileName = Dir()
Loop

Excelのシートに一覧出力

Dim fileName As String
Dim row As Long

row = 1
fileName = Dir("C:\Sample\*.*")

Do While fileName <> ""
    Cells(row, 1).Value = fileName
    row = row + 1
    fileName = Dir()
Loop

8. 注意点とまとめ

使い方のポイントと、気を付けたい注意点のまとめ

コピー後の補足
Application.CutCopyMode = False を入れると、コピー状態を解除できます。
重要な注意点
マクロ実行後は、基本的に Ctrl + Z で元に戻せません。 そのため、最初はコピーしたファイルで試す、バックアップを取る、 AIが作ったコードも内容を確認してから使う、といった意識が大切です。
コピー方法を使い分けられる全部コピー、値だけ、書式だけなど、目的に応じて選べます。
Range と Cells が基本セルの指定方法を理解すると、できることが広がります。
ループと条件分岐が重要繰り返し処理と判断処理で、自動化の幅が大きく広がります。
見た目も変更できるセルの色や文字色、太字なども自動化できます。
Excelの外も扱えるフォルダやファイルを読み込んで一覧化できます。
AI時代でも仕組みの理解が大切仕組みを知っていると、AIへの依頼がうまくなります。
