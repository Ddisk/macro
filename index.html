Excel マクロ・VBAでできること

Excelの作業を自動化する「マクロ」と、それを支える「VBA」について、 コードを長く読むのではなく、図解中心でイメージしやすくまとめたページです。

マクロとは AI時代に学ぶ意味 できること コピー Range / Cells ループ 条件分岐 色・文字色 フォルダ操作 注意点 まとめ

1. マクロとは？

マクロとは、Excelで何度も行う操作を、まとめて自動実行できる仕組みです。

👨‍💻
人が操作
コピー・貼り付け・計算・保存
➡
🧠
手順を覚えさせる
いつもやる流れを決める
➡
⚡
自動実行
ボタン1つでまとめて処理
VBAとは？
VBAは、ExcelなどのOfficeを自動で動かすためのプログラミング言語です。
つまり、マクロ＝自動化された処理、VBA＝その処理を作るための言葉というイメージです。

2. AI時代に、なぜ仕組みを知るのか？

今はAIに頼めば、VBAのコードそのものはかなり簡単に作れます。
でも、仕組みを少し知っておくと、AIへの依頼がうまくなり、出てきた内容も理解しやすくなります。

💡
やりたいことを考える
何を自動化したいか整理する
➡
🤖
AIへ依頼する
具体的に条件や流れを伝える
➡
🔍
内容を確認する
何をしているか大まかに分かる
△ あいまいな依頼

「Excelをいい感じに自動化して」

→ 目的や条件がぼんやりしていて、思った通りになりにくい

◎ 具体的な依頼

「A列にデータがある間、1行ずつ見て、80点以上ならB列に合格と表示するVBAを作って」

→ ループ・条件分岐・セル指定が明確で、AIにも伝わりやすい

ポイント
すべてのコードを暗記する必要はありません。
「何ができるか」「どういう仕組みで動くか」を理解しておくことが、AIを上手に使う近道です。

3. マクロでできること

VBAを使うと、Excel内の操作だけでなく、繰り返し処理や見た目の変更、ファイル操作まで幅広く自動化できます。

📋
コピー・貼り付け値だけ、書式だけ、数式ごと、など目的に応じて使い分けられます。
🔢
セルの指定Range や Cells を使って、1つのセルや範囲を自由に扱えます。
🔁
ループ処理同じ処理を何十回、何百回と繰り返せます。
🌿
条件分岐「もし〇〇なら～する」といった判断を自動化できます。
🎨
書式変更セルの色、文字色、太字、文字サイズなども変えられます。
📁
ファイル操作フォルダ内のファイルを読み込んだり、一覧化したりできます。

10. 注意点

コピー後の補足
Application.CutCopyMode = False を入れておくと、Excelのコピー状態を解除できます。
つまり、コピー後に出る点線の枠を消して、操作をすっきり終えられるイメージです。
マクロは基本的に「元に戻す」が使えない
普通のExcel操作なら Ctrl + Z で戻せますが、マクロを実行すると、操作履歴が消えてしまうため、元に戻せないことが多いです。

そのため、
  • 最初はコピーしたファイルで試す
  • 重要なデータはバックアップを取る
  • AIが作った内容も、何をするか確認してから使う
という意識が大切です。

11. まとめ

VBAは、Excelの繰り返し作業を自動化するだけでなく、 セル操作・判断・見た目の変更・ファイル操作まで幅広く扱えます。

コピーを使い分けられる 値だけ、書式だけ、数式ごとなど、目的に応じて選べます。
Range と Cells が基本 セルや範囲を指定する考え方が分かると、AIへの依頼もしやすくなります。
ループと条件分岐が重要 「繰り返す」「条件で分ける」が分かると、自動化の幅が一気に広がります。
見た目も変えられる 背景色、文字色、太字などを使って、見やすい表が作れます。
Excelの外にも広がる フォルダ内のファイル一覧化など、ファイル操作にも使えます。
AI時代でも理解は大事 コードを全部書けなくても、仕組みを知っていればAIを上手に使えます。
